The Seax in groups

Today's local stories, matched to the Facebook groups that want them

Each story is matched to a few groups in its own town. Tap Copy and open group: the wording is copied and the group opens. Paste, check you are posting as The Seax, add the picture if no preview appears, then press Post. Groups rest for a day after each post and each has a weekly limit, so the list stays small on purpose.

All groups and their rules

Uses the live edition and the group list in data/fb-groups.json (checked ). Ticks are saved on this device only. Court stories are never queued for groups. Links carry a tag for each group, so the analytics show which groups send readers.
